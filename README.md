# Ruta B2 · 西语固定搭配复习

每天 10 个 B2 动词固定介词搭配，按艾宾浩斯间隔（1/2/4/7/15/30/60 天）自动进入三轮复习。

在线地址：<https://tele-creator666.github.io/ruta-b2/>

## 说明

- 纯静态站点，直接托管在 GitHub Pages 上，无需服务器
- 词库 487 条、37 个分组，全部在 `data.js` 里，可离线使用
- 学习进度保存在浏览器本地存储（`ruta-b2-progress-v1`），换设备可用「设置」页导出/导入进度
- 你也可以自己添加搭配，标记为主题后同样进入复习队列

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构与图标 |
| `styles.css` | 样式 |
| `app.js` | 排期、三轮复习、词库管理逻辑 |
| `data.js` | 内置词库（`window.CARD_GROUPS`） |

想本地预览：在本目录起一个静态服务器即可，例如 `python -m http.server 4173`。
