# Ruta B2 · 西语固定搭配复习

每天 10 个 B2 动词固定介词搭配，按艾宾浩斯间隔（1/2/4/7/15/30/60 天）自动进入三轮复习。

在线地址：<https://tele-creator666.github.io/ruta-b2/>

## 导入自己的搭配

「设置 → 词库管理」支持三种喂料方式，都不要求先排版：

- **直接粘贴**：乱排版的笔记、编号列表、破折号说明、从 Excel 或在线表格整块复制的内容都能认。程序按「西语＋中文」的行结构自动配对，序号、页码、URL、纯中文说明行会被跳过。
- **选择文件**：`.txt` `.csv` `.tsv` `.md`（自动识别 Tab / 逗号 / 分号 / Markdown 表格）、`.json`、以及**带高亮的 PDF**。
- **PDF 高亮**：只提取你用高亮／下划线标注的那些位置。标注里带中文释义的直接成卡；只标了整句的，会自动从句中挑出「框架短语」「动词＋介词」「名词＋介词」当作候选。

解析后会弹出预览清单：常见 B2 词组默认勾选，单个词、A1/A2 入门搭配、生僻口语、像整句的片段会被标注并默认不勾选；释义可以直接在清单里改。已有搭配会自动识别为重复并隐藏。

高亮提取依赖打包在 `vendor/` 里的 pdf.js（Apache-2.0，Mozilla），全部在本机浏览器内完成，文件不会上传到任何服务器。扫描版 PDF（没有文字层）无法提取。

## 说明

- 纯静态站点，直接托管在 GitHub Pages 上，无需服务器
- 内置词库 394 条常见 B2 固定搭配（已剔除入门项、重复变体、谚语俚语和单个词）
- 学习进度保存在浏览器本地存储（`ruta-b2-progress-v1`），换设备可用「设置」页导出/导入进度
- 你也可以自己添加搭配，标记为主题后同样进入复习队列

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构与图标 |
| `styles.css` | 样式 |
| `app.js` | 排期、三轮复习、词库管理和导入预览 |
| `importer.js` | 导入引擎：文本／表格／高亮 PDF → 候选搭配，并做 B2 分级 |
| `level-lists.js` | 入门级与生僻条目名单，供导入时降级 |
| `data.js` | 内置词库（`window.CARD_GROUPS`） |
| `vendor/` | pdf.js 4.10（Mozilla, Apache-2.0），本地解析 PDF |

想本地预览：在本目录起一个静态服务器即可，例如 `python -m http.server 4173`。
